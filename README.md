## 🛠️ Setup

### How to Clone and Run the Project Locally

**1. Clone the Repository** 🖥️  
First, clone the project to your local machine by running:
```bash
git clone https://github.com/pavan0209/portfolio.git
```

**2. Navigate to the Project Directory** 📂  
After cloning, move to the project folder:
```bash
cd portfolio
```

**3. Install Dependencies** ⚙️  
Fetch all the required dependencies by running:
```bash
flutter pub get
```

**4. Run the Project** ▶️  
Finally, run the app:
```bash
flutter run
```
